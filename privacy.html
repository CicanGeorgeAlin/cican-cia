PRIVACY & STORAGE NOTICE

PRIVACY-FIRST DESIGN

CICAN is currently designed as a client-side educational website. The gameplay profile and progress used by the current site are stored locally in the user's browser. CICAN does not require an account or ask the user to submit personal information to use the current experience.

1. WHAT CICAN STORES

The current game may use browser localStorage to remember simulated gameplay state, such as XP, discoveries, verified investigations, lessons, access-stage progress, and related game settings. This information is stored on the user's device/browser for the CICAN experience. It is not intentionally transmitted by the CICAN application to a CICAN database.

2. DEVICE STORAGE

Local storage and similar technologies are subject to applicable electronic-privacy rules. CICAN uses local browser storage for the operation of requested gameplay functionality. If future versions introduce non-essential tracking, analytics, advertising, profiling, or other device-storage technologies, the site will be reviewed and an appropriate consent mechanism will be added where legally required.

3. NO ACCOUNT REQUIRED

The current CICAN experience does not require registration, login, a user account, or submission of a name, address, telephone number, government identifier, security clearance information, or classified information.

4. DO NOT SUBMIT CLASSIFIED OR SENSITIVE INFORMATION

CICAN is a public-record educational project. Users must not submit classified, controlled, export-restricted, law-enforcement-sensitive, personal, or otherwise non-public information to CICAN through any future form, message, upload, or other interface.

5. HOSTING & TECHNICAL DATA

A public website necessarily relies on hosting and network infrastructure. Hosting providers, browsers, networks, or security systems may process technical information such as IP addresses, request information, timestamps, or security logs under their own policies. CICAN does not represent that it controls such infrastructure data. Users should consult the applicable hosting provider's privacy documentation where relevant.

6. EXTERNAL GOVERNMENT SOURCES

When a user opens a CIA Reading Room or other government source, the user leaves the CICAN site and becomes subject to the external site's own privacy, security, cookie, and data-handling policies. CICAN does not control those practices.

7. FUTURE FEATURES

If CICAN later introduces accounts, email, analytics, advertising, payments, cloud saves, comments, uploads, newsletters, or other processing of personal data, this notice must be updated before those features are deployed and the applicable legal basis, transparency, retention, rights, and consent requirements will be assessed.

8. DATA PROTECTION

Where CICAN processes personal data in the future, the applicable requirements of the GDPR and Irish data-protection law will be assessed according to the actual processing activity. This notice is intended to describe the current technical design, not to claim that future processing is already compliant.

9. CHANGES

This notice should be reviewed whenever the website architecture or data-processing practices change.
